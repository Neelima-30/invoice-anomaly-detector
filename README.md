# Invoice Anomaly Detector

An AI-powered web application that analyzes invoice images and detects potential anomalies using Machine Learning and Computer Vision techniques.

## 🚀 Project Overview

The **Invoice Anomaly Detector** is designed to help identify suspicious or unusual invoice information automatically.

The application allows users to upload an invoice image and analyzes the extracted information to identify possible anomalies such as unusual amounts, inconsistent values, or other irregular patterns.

## ✨ Features

* 📄 Upload invoice images
* 🔍 Analyze invoice information
* 🤖 Machine Learning-based anomaly detection
* 🧾 Invoice data extraction
* ⚠️ Identify potentially suspicious invoice details
* 🌐 Simple and user-friendly web interface
* 📊 Display analysis results clearly

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Neelima-30/invoice-anomaly-detector.git
```

### 2. Navigate to the project directory

```bash
cd invoice-anomaly-detector
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application using:

```bash
streamlit run app.py
```

The application will open in your browser.
